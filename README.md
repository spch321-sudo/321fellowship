## 上傳（GitHub：spch321-sudo/321fellowship）
把這個 zip 裡的 5 個檔案一起上傳覆蓋到網站根目錄：
- index.html
- data.json（奉獻帳號已更新；一定要一起換，否則舊帳號會蓋回來）
- media.js（新檔：配樂、錄音錄影、我的作品）
- sw.js（新版，自動更新）
- version.json（新檔，版本號）

其他檔案（圖示、manifest.json）不用動。
上傳後約 1～10 分鐘生效；已裝在手機主畫面的 App 打開或切回來時會自動換成新版。

詩歌庫直接使用同網域《321互動聖經》的 music.json 與音檔，不必另外上傳。
